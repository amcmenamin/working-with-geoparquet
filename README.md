Working with Geoparquet provides some open code to play with geoparquet files.

This code base has been developed to help access data. It is not considered production code.

cloud_to_geoparquet support methods to access new zealand and other common geoparquet datasets and optional creating a duckdb catalogue to support SQL query against parquet files.

rasterbands_to_geoparquet - WORK IN PORGRESS - mainly around concept of converting multi band rasters in single bands or geoparquet. May be deleted as concept at this point.
